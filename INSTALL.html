INSTALL/UPDATE: Copilot + rad-mcp

Pick one install path. The default tab is the simplest local setup: VS Code Copilot with a local stdio MCP server and skills installed together by one combined script. These same flows are also the supported update paths after git pull; rerun the relevant installer to refresh MCP config, skills, and local stdio prerequisites.

Before You Start

  1. Use only the official GitHub Copilot product for your IDE.
  2. Clone or update the repository.
  3. Run installer commands from the repository root.
git clone https://github.com/uzigolan/rad-agent-toolkit.git
cd rad-agent-toolkit

# or, inside an existing clone
git pull
Safety note
The installers create and use a repo-local Python environment under rad-mcp-server/server/.venv. They do not install Python packages system-wide.

Install Paths

Install MCP stdio and Copilot on VS Code

This is the default and simplest local install path.

.\rad-mcp-server\scripts\install\skills_and_mcp\install-stdio-copilot-vscode.ps1

What it does

  1. Prepares the local stdio MCP server.
  2. Builds or reuses the local catalog as needed.
  3. Installs VS Code Copilot MCP config.
  4. Installs Copilot skills.

Useful options

.\rad-mcp-server\scripts\install\skills_and_mcp\install-stdio-copilot-vscode.ps1 -Knowledge served
.\rad-mcp-server\scripts\install\skills_and_mcp\install-stdio-copilot-vscode.ps1 -Knowledge bundled
.\rad-mcp-server\scripts\install\skills_and_mcp\install-stdio-copilot-vscode.ps1 -MibDir C:\MIBS
.\rad-mcp-server\scripts\install\skills_and_mcp\install-stdio-copilot-vscode.ps1 -SkipCatalog

After install

  1. Reload the VS Code window with Ctrl + Shift + P -> Developer: Reload Window.
  2. Open Copilot settings or Agent Customizations from the Copilot UI.
  3. In MCP Servers, make sure rad-mcp appears and click Start or Restart if needed.
  4. In Skills, search for rad- and verify you see 8 or more skills.
  5. Switch Copilot Chat to Agent mode.
  6. Test with rad agent, list the managed devices.

Problems

'PowerShell' is not recognized

If you are already inside a PowerShell prompt, do not launch PowerShell again. Run the script directly:

.\rad-mcp-server\scripts\install\skills_and_mcp\install-stdio-copilot-vscode.ps1

If execution policy blocks it:

Set-ExecutionPolicy -Scope Process -ExecutionPolicy Bypass
.\rad-mcp-server\scripts\install\skills_and_mcp\install-stdio-copilot-vscode.ps1

If the machine uses PowerShell 7:

pwsh -ExecutionPolicy Bypass -File .\rad-mcp-server\scripts\install\skills_and_mcp\install-stdio-copilot-vscode.ps1

Check what exists:

Get-Command pwsh, powershell.exe

MCP installed but Copilot does not see it

  1. Reload or restart the IDE.
  2. Accept the MCP trust prompt.
  3. Use Agent mode, not Ask or Edit mode.
  4. Re-run the installer with -Reconfigure if an old config was kept.

Data exists in the repo but the assistant says it is missing

  1. Bundled mode may read only shipped skill references under skills/.../references/.
  2. Served mode must use MCP knowledge tools, not arbitrary workspace disk search.
  3. If a tracked reference artifact is missing, update the repo and reinstall.

Verify with one prompt per technology

  1. rad agent, add my device: name lab-etx2, host 172.17.163.205, family etx2, group lab, user su, password 1234
  2. rad agent, according to the ETX-2 manual, explain ERP failover timers and revertive behavior
  3. abayev, show the active alarms on sf-163-187
  4. rad agent, check SNMP on etx2v-1 and report its exact firmware, sysObjectID, and detected family
  5. rad agent, list all MEA util fctl commands from stored data
  6. rad agent, in Altera docs explain AWVALID/WVALID timing expectations and point to the relevant figure
